# 0009 — Executor qualification boundary

- Status: experimental contract
- Date: 2026-09-22

P8.1 introduces executor identity, controlled environment/task/budget contracts, external observations, explicit comparison axes, and deterministic summaries. It contains no concrete adapter, SDK, subprocess, network, or LLM integration.

Declared capability is metadata, not qualification evidence. P8 separates execution outcome from external acceptance and preserves unknown measurements as unknown. It does not choose a winner or promote an executor; those decisions remain future P9 work.
